Duration-based exercises are marked with `[duration]`; all others are assumed to be repetitions-based.

# Naming convention

Names follow the pattern `Movement, qualifier, qualifier`:

1. The common movement name comes first, so variants of the same movement sort together in the app.
2. Qualifiers follow, separated by commas, in this order: equipment, attachment or grip, other (single-leg, seated, ...).
3. Equipment is named only when the movement is done with more than one kind (`Biceps curl, barbell` vs `Biceps curl, dumbbell`; plain `Leg press`).
4. Sentence case (capitalize only the first word and proper names such as `Bulgarian` or `Roman`), singular movements, no hyphens or "with". `Biceps` / `Triceps`, not `Bicep` / `Tricep`.

Exercises are identified by name. Renaming one requires an entry in `RENAMES` in `js/db.js` and a database upgrade, so existing history and old backups follow the new name.
